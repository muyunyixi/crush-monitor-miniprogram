# Crush Monitor 小程序 · 可行性验证 v0.2.0

微信真机已经验证：原生输入框长按粘贴可以一次收到多条微信聊天消息。本仓库继续验证本机对话保存、增量追加、从相册选取截图。

## 导入与真机测试

1. 下载此仓库，解压到本机。
2. 微信开发者工具 → 导入项目 → 选择含有 `project.config.json` 的仓库根目录。
3. 项目配置中的 AppID 是对应已提供截图中的小程序 AppID；如你的测试小程序不同，导入时选择自己的 AppID。
4. 点击「编译」「预览」，用手机微信扫码。
5. 在微信聊天多选复制文字，回到小程序长按输入框粘贴，点击「保存新增记录」。
6. 退出再进入，确认文字仍在。再次复制整段旧记录加新消息，观察只追加新增的行；同一段再次提交应提示内容已保存。
7. 点击「新建对话」、更改标题并保存；从相册选截图，确认可以预览。

此版按**非空文本行**存储，尚未将微信复制格式解析为带说话人和时间戳的消息；重复检测仅处理整段重贴或与上一段尾部重叠的文字，并非通用内容去重。截图只在当前页面临时显示，不会保存、上传或做 OCR。

## 安全与后续

本版本不请求网络，不上传聊天记录，也无需配置 AppSecret。**AppSecret 只能存放在服务端的 Secret 中**，不能写入公开仓库或小程序源码。已存在 v0.1.0 本机草稿时，会带入新版本输入框，不自动当成已保存的聊天记录。微信 OCR 和现有 Worker 的对接将在后续版本完成。
