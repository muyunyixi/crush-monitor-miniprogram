# Crush Monitor 小程序 · 粘贴可行性验证 v0.1.0

这是独立的微信小程序原生项目。**当前只验证微信多选复制后的长按粘贴，以及同一手机上的本地保存**；分析、截图识别、云端登录和后端接口尚未接入。

## 导入与真机测试

1. 下载此仓库，解压到本机。
2. 微信开发者工具 → 导入项目 → 选择含有 `project.config.json` 的仓库根目录。
3. 项目配置中的 AppID 是对应已提供截图中的小程序 AppID；如你的测试小程序不同，导入时选择自己的 AppID。
4. 点击「编译」，然后点击「预览」，用管理员或测试成员微信扫码，在**真机小程序**里操作；模拟器不能证明安卓微信多选粘贴是否正常。
5. 在微信聊天多选并复制至少三条文字，回到小程序，长按输入框选择「粘贴」。查看输入框、下面的完整内容以及字符数和非空行数。
6. 退出小程序再进入，确认内容还在；点「清空记录」可移除本机数据。

请记录手机型号、系统版本、微信版本、选择的消息条数、粘贴后收到的条数。若仍只有一条，可以对比长按粘贴与输入法剪贴板粘贴，并反馈结果。

## 安全与后续

本版本不请求网络，不上传聊天记录，也无需配置 AppSecret。**AppSecret 只能存放在服务端的 Secret 中**，不能写入公开仓库或小程序源码。微信 OCR 和现有 Worker 的对接要等真机粘贴可行性验证之后，再作为单独步骤实现。
